vibespin.scripts.benchmarks package

Submodules

scripts.benchmarks.throughput module

Comprehensive scaling benchmark for the VibeSpin Simulation Project.

Measures performance of MC sweeps and analysis functions across different lattice sizes and saves results to results/benchmarks/scaling_benchmark.npz for use by notebooks/Performance_Benchmarks.ipynb.

Usage

python scripts/benchmarks/throughput.py python scripts/benchmarks/throughput.py –sizes 64 128 256 512 –sweeps 200
