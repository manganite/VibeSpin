Ising Model: Autocorrelation and Equilibration Analysis

This notebook investigates the equilibration behavior and autocorrelation of the 2D Ising model [1] comparing three Monte Carlo update schemes: Random-site Metropolis [2], Checkerboard Metropolis, and the Wolff cluster algorithm [3].

The efficiency of these algorithms is highly temperature-dependent, particularly near the Onsager critical temperature \(T_c = 2/\ln(1+\sqrt{2}) \approx 2.269\). Near \(T_c\), local update schemes suffer from critical slowing down [4], where the time required to generate independent samples scales poorly with system size. The Wolff algorithm is designed to mitigate this by performing collective updates.

[ ]:

from __future__ import annotations

import matplotlib.pyplot as plt
import numpy as np
from models.ising_model import IsingSimulation

# Constants
TC_ISING = 2.0 / np.log(1.0 + np.sqrt(2.0))
L = 64
N_STEPS = 1000
TEMPS = [0.8 * TC_ISING, TC_ISING, 1.2 * TC_ISING]
TEMP_LABELS = ["Below Tc", "At Tc", "Above Tc"]
UPDATES = ["random", "checkerboard", "wolff"]

print(f"Critical Temperature Tc: {TC_ISING:.6f}")

Raw Magnetization Time Series

We run simulations starting from a random configuration (high-energy state) without any equilibration steps. This allows us to visualize how quickly each algorithm approaches the equilibrium regime at different temperatures.

[ ]:

results = {}

for T in TEMPS:
    results[T] = {}
    for update in UPDATES:
        sim = IsingSimulation(size=L, temp=T, update=update, seed=42)
        # Capture raw time series from step 0
        mags, _ = sim.run(n_steps=N_STEPS)
        results[T][update] = mags

print("Simulations complete.")

Visualization of Equilibration

The following plots show the evolution of the absolute magnetization \(|M|\) over 000$ steps. Note the differences in relaxation speed and fluctuation scales between the algorithms and temperature regimes.

[ ]:

fig, axes = plt.subplots(3, 3, figsize=(15, 10), sharex=True, sharey=True)

for i, T in enumerate(TEMPS):
    for j, update in enumerate(UPDATES):
        ax = axes[i, j]
        mags = np.abs(results[T][update])
        ax.plot(mags, lw=1)
        if i == 0:
            ax.set_title(f"Update: {update}")
        if j == 0:
            ax.set_ylabel(f"{TEMP_LABELS[i]} |M|")
        if i == 2:
            ax.set_xlabel("Step")
        ax.grid(alpha=0.3)

plt.tight_layout()
plt.show()
